# 😇 Angel Artic

> **Speak • Play • Shine** — Gentle Articulation & Speech Sound Practice for Children  
> Official Publisher: **Hope Bridge Digital** ([https://hopebirdgedigital.site/](https://hopebirdgedigital.site/))

Angel Artic is an evidence-based speech practice application designed for children learning speech sound production, supporting children with speech sound delays, childhood apraxia of speech, Down syndrome, or autism.

---

## 🌟 Key Features
- **🗣️ 17 Speech Sounds & Comprehensive Decks:** Covers initial, medial, and final word positions across phonemes from early sounds (`/p/`, `/b/`, `/m/`) to advanced phonemes (`/r/`, `/s/`, `/th/`, `/ch/`).
- **🎙️ Patented Microphone Voice-Gate:** Distinguishes ambient room noise from genuine vocal effort. Silence never earns a score, but effort is always praised.
- **👄 3D Visual Mouth & Tongue Guides:** Anatomical animations demonstrating exact placement of lips, teeth, and tongue for tricky sounds.
- **📷 Custom Words & Family Voices:** Parents can record their own voice and attach family photos for personalized practice.
- **🎮 Adventure Quest & Rewards:** Motivation worlds, sticker albums, avatar outfits, and positive reinforcement without sensory over-stimulation.
- **📊 Parent & Clinician Hub:** 14-day accuracy trends, before/after audio comparison, and one-tap PDF export.
- **🛡️ 100% Private & Offline:** COPPA compliant, zero third-party ads, zero tracking scripts. All voice recordings stay strictly on the user's device.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Expo CLI (`npx expo`)

### Installation & Run
```bash
# Install dependencies
npm install

# Run locally in development
npx expo start

# Run web version
npx expo start --web
```
